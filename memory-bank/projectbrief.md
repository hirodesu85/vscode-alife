# VSCode Alife - プロジェクト概要

## 目的

VSCode 内で人工生命シミュレーション（Boid モデル）を実行できる拡張機能を提供し、開発者が人工生命システムを直感的に理解し、学習できる環境を構築すること。

## 主要機能

1. インタラクティブな Boid シミュレーション

   - 複数の Boid エージェントの群れ行動シミュレーション
   - クリックによる新しい Boid の追加
   - ピクセルアートスタイルの視覚的表現

2. VSCode 統合

   - エクスプローラービューへのシームレスな統合
   - WebView 技術を活用したリアルタイムレンダリング

3. シミュレーションパラメータ
   - 群れ行動の 3 つの基本ルール（分離、整列、結合）の実装
   - 最大速度制限
   - 境界判定と反射

## ターゲットユーザー

- 人工生命やシミュレーションに興味を持つ開発者
- プログラミング学習者
- VSCode ユーザー

## 技術要件

- TypeScript/JavaScript
- VSCode 拡張機能 API
- HTML5 Canvas
- Webview インテグレーション

## プロジェクトゴール

1. シンプルで直感的なインターフェース
2. 効率的なシミュレーション処理
3. 教育的価値の提供
4. 拡張可能なアーキテクチャ
